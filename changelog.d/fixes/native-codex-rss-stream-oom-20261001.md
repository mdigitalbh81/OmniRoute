Fix Native Codex long-session RSS growth on Antigravity by releasing request abort listeners when SSE streams complete, account SSE backpressure in bytes, and add an absolute RSS admission fuse. Heuristic ultra compression for large /v1/responses histories now runs in a bounded worker thread (default 1024 MiB old-generation budget, configurable with OMNI_COMPRESSION_WORKER_MAX_OLD_MB), so a pathological compression job fails open instead of driving the host into global OOM.
